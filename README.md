# AI Drawing Tutor & Masterclass

An interactive web-based drawing tutor designed to help users upload references and learn to draw step-by-step using structuralization, shape manipulation, pencil grips, shading techniques, and pen-and-ink methods.

## Features
- **3 Drawing Modes**: Kids/Beginners, Realistic Pencil, and Pen & Ink.
- **Progressive Stages**: From basic 3D shapes to core shadows and highlights.
- **Interactive Practice Canvas**: Draw, erase, and save your progress directly in your browser or phone.
